# PyPARIS (Deprecated)
> [!CAUTION]
> This package has been fully integrated into PyECLOUD and it is installed alongside it, please refer to that repository:
> https://github.com/PyCOMPLETE/PyECLOUD
>
> **v2.6.0 is the last standalone release of PyPARIS.** This repository is no longer maintained.
> Starting from PyECLOUD v8.9.0, PyPARIS is distributed as part of PyECLOUD (reported as `2.6.0+pyec<PyECLOUD version>`),
> and all further development happens there. The import name is unchanged (`import PyPARIS`).

This package should be tested using the examples in:

https://github.com/PyCOMPLETE/PyPARIS_CoupledBunch_sim_class
